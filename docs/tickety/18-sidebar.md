# 18 — Sidebar

**Rozmiar:** M · **Typ:** AFK · **Blokowany przez:** 10, 17

## Co zbudować

Zwijalny sidebar (accordion, animacje z transitions-dev): najbliższa zmiana (zawsze widoczna), bloki cykliczne z paskami kolorów, backlog z licznikiem przy nagłówku, filtry widoczności. Sticky, własny scroll niezależny od Plannera. Przełącznik pokaż/schowaj panel.

## Kryteria akceptacji

- [ ] Sekcje zwijają się niezależnie; liczniki pokazują liczbę pozycji
- [ ] Scroll sidebaru nie rusza Plannera i odwrotnie
- [ ] Filtry ukrywają/pokazują typy bloków w Plannerze
- [ ] `prefers-reduced-motion` respektowane
