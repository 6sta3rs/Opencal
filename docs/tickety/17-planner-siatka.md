# 17 — Planner: siatka godzinowa

**Rozmiar:** L · **Typ:** AFK · **Blokowany przez:** 02

## Co zbudować

Widok dnia/tygodnia z osią godzinową (strefa czasowa widoczna). Instancje bloków renderowane wg DESIGN.md: karta z paskiem akcentu 2–3 px w kolorze typu, blok noclegu z wzorem ukośnych pasków + etykietą.

## Kryteria akceptacji

- [ ] Bloki z API widoczne na osi we właściwych godzinach i dniach
- [ ] Typ bloku rozpoznawalny kolorem ORAZ etykietą/ikoną (WCAG, daltoniści)
- [ ] Blok noclegu natychmiast odróżnialny od zwykłej zmiany
- [ ] Zmiana 17:00–02:00 renderuje się poprawnie przez granicę dnia
